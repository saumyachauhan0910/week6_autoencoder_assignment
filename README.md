# Week 6 - Autoencoder for Image Denoising

## Objective
Build a deep learning autoencoder that removes Gaussian noise from MNIST handwritten digit images.

## Dataset
- MNIST Dataset (TensorFlow/Keras)

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Workflow
1. Load the MNIST dataset
2. Normalize the images
3. Add Gaussian noise
4. Build a Convolutional Autoencoder
5. Train the model
6. Generate denoised images
7. Compare Original, Noisy, and Denoised images

## Results
The trained autoencoder successfully reconstructed clean handwritten digit images from noisy inputs.
